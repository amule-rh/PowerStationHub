# PowerStationHub

Bilingual (ES/EN) editorial affiliate website focused on portable power stations, batteries and solar energy.

## Stack
- Static HTML + CSS + minimal JavaScript
- GitHub for source control
- Vercel for deployment
- Google Search Console for indexing

## SEO foundation
- Canonical URLs
- ES/EN hreflang
- Open Graph and Twitter metadata
- JSON-LD WebSite/WebPage/Article markup
- Semantic headings and internal links
- XML sitemap
- robots.txt
- Mobile-first responsive CSS
- Clean trailing-slash URLs

## Launch checklist
1. Import this repository into Vercel.
2. Connect the production domain.
3. Verify the domain in Google Search Console.
4. Submit `/sitemap.xml`.
5. Inspect representative ES and EN URLs.
6. Add the final legal controller/contact details.
7. Add approved affiliate URLs after acceptance into the relevant programs.
