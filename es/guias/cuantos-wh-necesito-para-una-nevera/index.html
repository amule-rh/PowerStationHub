Cuántos Wh necesito para una nevera

Método para estimar los Wh de una nevera, entender los ciclos del compresor y elegir un margen razonable.

Regla rápida: capacidad (Wh) determina principalmente la energía disponible; potencia continua (W) determina qué aparatos puedes alimentar; el pico importa para cargas con arranque.

Wh no es lo mismo que W

Los W describen potencia instantánea. Los Wh describen energía acumulada. Para una nevera, los Wh diarios son la referencia más útil para autonomía.

Fórmula sencilla

Wh/día ≈ W medios × horas de funcionamiento equivalentes. La potencia nominal no significa que el compresor esté funcionando a esa potencia durante todo el día.

Añade margen

Después de estimar los Wh diarios, añade margen para pérdidas y condiciones reales.
